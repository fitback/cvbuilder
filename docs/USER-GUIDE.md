# ResumeMatcher 用户手册

> 版本：v0.4.0 | 更新日期：2026-05-29

---

## 一、产品简介

ResumeMatcher 是一款面向求职者的 AI 简历优化平台，帮你完成三件事：

1. **解析**：上传简历，AI 自动提取结构化信息
2. **分析**：匹配目标岗位 JD，AI 评估匹配度并给出优化建议
3. **生成**：AI 根据分析结果重新撰写高匹配度简历，支持在线编辑和导出

---

## 二、注册与登录

访问网站后，首次使用需要注册：

1. 点击「登录 / 注册」按钮
2. 输入手机号和密码
3. 注册成功即赠送 **50 积分**

## 三、核心操作流程

### 流程总览

```
上传简历 → 解析简历 → 编辑解析结果 → 简历分析 → 生成优化简历 → 导出
```

### 3.1 第一步：上传简历

1. 点击左侧导航栏「上传简历」或仪表盘「上传新简历」
2. 拖拽或点击上传 PDF / Word 文件（限 5MB 以内）
3. 上传后系统自动解析，页面显示「解析中...」
4. 解析完成显示「解析完成」，自动跳转

> 解析过程通常需要 10-30 秒，请耐心等待。

### 3.2 第二步：查看与编辑解析结果

在仪表盘点击已解析简历的 **「解析」** 按钮，进入简历编辑页：

| 可以编辑的字段 | 说明 |
|--------------|------|
| 基本信息 | 姓名、手机、邮箱、地点、个人摘要 |
| 工作经历 | 公司、职位、时间、描述（支持多条） |
| 项目经历 | 项目名称、角色、时间、描述（支持多条） |
| 教育背景 | 学校、专业、学历、时间（支持多条） |
| 专业技能 | 技能列表，逗号分隔 |

- 点击「+」添加新条目
- 点击垃圾桶图标删除条目
- 修改完成后务必点击 **「保存」**

> 这一步很重要：AI 分析是基于你编辑后的简历内容进行的，请确保信息准确完整。

### 3.3 第三步：创建岗位 JD

在进行简历分析之前，需要先创建目标岗位的 JD：

1. 点击左侧导航栏「我的 JD」
2. 点击「新建 JD」
3. 填写岗位名称、公司名称（可选）、JD 正文
4. 保存

> 建议 JD 内容尽量详细，包含技术栈要求、工作年限、学历要求等，AI 分析会更精准。

### 3.4 第四步：AI 简历分析

1. 在简历编辑页点击 **「简历分析」** 按钮
2. 系统会跳转到分析页面，在左侧选择目标岗位 JD
3. 点击 **「AI 分析」** 按钮
4. 等待约 15-30 秒，AI 完成分析

分析结果包含三个部分：

| 模块 | 内容 |
|------|------|
| JD 核心解码 | 岗位的核心需求 + 隐性考察点 |
| 优化建议 | 针对简历各模块的修改建议，附修改示例 |
| 排雷清单 | 简历中的错误、冗余、表述问题 |

还有一个 **匹配度分数（0-100）**，直观展示你与该岗位的匹配程度。

**积分消耗**：每次分析消耗 **30 积分**，积分不足时将提示充值。

### 3.5 第五步：生成优化简历

分析完成后，在分析结果页面点击 **「生成优化简历 · 消耗 50 积分」**，AI 会：

1. 基于分析建议和原始简历
2. 自动撰写一份高度匹配目标岗位的新简历
3. 输出为 Markdown 格式

生成耗时约 20-40 秒。

### 3.6 第六步：编辑导出

生成后可以：

- **在线编辑**：点击「确认」，输入简历名称后保存，跳转到编辑器
- **复制**：一键复制 Markdown 内容到剪贴板
- **导出 PDF**：生成 A4 格式的专业 PDF 简历
- **导出 DOCX**：生成 Word 文档，可在 Microsoft Word 中继续编辑

> 保存后的简历在仪表盘「生成的简历」区域可以找到，随时重新编辑或导出。

## 四、积分系统

### 积分获取

| 方式 | 说明 |
|------|------|
| 注册赠送 | 新用户注册即送 50 积分 |
| 充值 | 点击侧边栏「充值」，支付宝扫码支付后自动到账 |

### 积分消耗

| 操作 | 消耗 |
|------|------|
| AI 分析简历 | 30 积分 / 次 |
| AI 生成简历 | 50 积分 / 次 |

> 积分不足时系统会提示充值。

### 查看积分

侧边栏底部实时显示当前积分余额，点击「积分明细」可查看历史交易记录。

## 五、移动端适配

- **桌面端**：左侧侧边栏导航，所有功能均可使用
- **移动端**：底部 Tab 栏导航，支持上传、查看简历等核心操作
- **简历编辑器**：建议在桌面端使用，编辑体验更好

## 六、常见问题

**Q：上传简历后一直显示「解析中」？**
A：解析通常需要 10-30 秒，如果超过 2 分钟仍然未完成，可能是文件格式异常，建议截图后重新上传。

**Q：分析结果不满意怎么办？**
A：可以回到简历编辑页修改解析结果，修复 AI 提取不准确的信息，然后重新分析。

**Q：积分不足怎么办？**
A：点击侧边栏「充值」，扫描二维码支付后联系管理员审核。充值比例：10 积分 = 1 元。

**Q：生成的简历可以修改吗？**
A：可以。生成后点击「确认」保存，进入编辑器可自由修改 Markdown 内容，修改后重新保存即可。

**Q：支持哪些文件格式？**
A：PDF 和 Word（.docx），文件大小不超过 5MB。
