# 管理员注册用户记录设计

> **日期：** 2026-08-20
> **状态：** 本地实现完成，待浏览器验收和用户确认
> **范围：** 管理后台只读查看注册用户记录

## 目标

在管理员后台增加注册用户记录区域，让管理员查看当前平台注册用户及其基础状态。手机号对管理员显示完整号码；普通用户不能访问该接口或页面数据。

## 范围

### 包含

- 管理员专用只读接口 `GET /auth/users`
- 用户列表按注册时间倒序排列
- 管理后台展示用户总数、完整手机号、角色、积分、注册时间
- 桌面端表格、移动端卡片布局
- 返回统一 API 响应格式

### 不包含

- 删除用户
- 修改用户角色
- 修改用户积分
- 查看密码、密码哈希、登录凭证
- 分页、搜索和导出

## 权限与数据安全

接口同时使用 `AuthGuard` 和 `AdminGuard`。服务端查询只选择以下字段：

```text
id
phone
role
points
createdAt
```

`passwordHash`、登录 token 和其他内部字段不得出现在响应中。手机号不脱敏，但仅对已通过管理员权限校验的请求返回。

## API 设计

```text
GET /auth/users
Authorization: Bearer <admin-token>
```

成功响应由全局拦截器包装：

```json
{
  "success": true,
  "data": [
    {
      "id": "uuid",
      "phone": "13800000000",
      "role": "user",
      "points": 50,
      "createdAt": "2026-08-20T04:00:00.000Z"
    }
  ]
}
```

普通用户或未登录请求返回现有统一错误格式，不泄露用户列表数据。

## 前端设计

管理员页面新增“注册用户”区域，位于服务状态和充值记录之间，包含：

- 标题：注册用户
- 辅助信息：共 N 位用户
- 桌面端：用户、角色、积分、注册时间表格
- 移动端：每位用户一张卡片
- 空状态：暂无注册用户
- 加载状态：与现有后台列表一致
- 加载失败：沿用页面错误提示和重试入口

手机号显示完整值。角色使用中文标签：管理员、普通用户；时间使用 `zh-CN` 格式。

## 实现文件

- `packages/backend/src/auth/auth.controller.ts`：增加管理员保护的 GET 路由
- `packages/backend/src/auth/auth.service.ts`：增加只读用户查询
- `packages/frontend/app/admin/page.tsx`：加载并展示用户记录
- `packages/shared/`：如现有类型约定需要，再补充用户列表类型

不修改 Prisma schema，不新增数据库迁移。

## 验收标准

- [ ] 管理员能看到全部注册用户
- [ ] 管理员看到完整手机号
- [ ] 普通用户访问接口返回无权限
- [ ] 未登录访问接口返回未登录
- [ ] 响应不包含 `passwordHash` 或其他凭证字段
- [ ] 桌面端表格可读，移动端无横向溢出
- [ ] 用户按注册时间倒序显示
- [ ] shared、backend、frontend 构建通过
- [ ] 不执行推送或云端部署
